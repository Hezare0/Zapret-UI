# Zapret UI

<img src="assets/zapret-client.png" width="96" alt="Zapret UI icon">

Windows-клиент на Python + PySide6 для [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube).
Текущая версия: **0.4.0**.

Готовый релиз — один автономный EXE. Python, PySide6, DLL и portable Git входят в файл; устанавливать их отдельно не нужно.
Сама папка zapret подключается отдельно.

## Возможности

- Выбор, запуск и остановка `general*.bat`. Права администратора запрашиваются один раз при открытии клиента.
- Скачивание официального zapret прямо из окна. Git-копия создаётся в `zapret-discord-youtube` рядом с EXE и сразу выбирается в клиенте.
- Собственные Standard-тесты: клиент запускает конфигурации последовательно и проверяет HTTP/TLS/ping параллельно по целям. Результат — успешные цели / все цели, средний ping и детали каждой цели.
- Отмена проверки кнопкой; закрытие окна отменяет тест, сохраняет результат и завершает очистку перед выходом.
- Сохранение результатов и даты каждого завершённого батника, восстановление выбора и журнала после перезапуска.
- Импорт консольного вывода и файлов из `utils/test results`.
- Проверка обновлений ветки `main` и отдельная кнопка применения. Изменённый через `service.bat` IPSet сохраняется во время обновления.
- Проверка GitHub Release самого UI и установка новой версии автономного EXE из окна. ZIP проверяется по SHA-256 GitHub, после перезапуска старый EXE отправляется в корзину. При ошибке запуска выполняется откат.
- Собственная иконка окна, EXE и ярлыка; ICO содержит размеры от 16 до 256 пикселей.

Клиент использует отдельную распакованную сборку zapret. Бинарные файлы zapret в этот репозиторий не включены.

## Требования

- Windows 10/11 x64; проверено на Windows 11.
- Для запуска из исходников — Python 3.13 x64.
- Для обновления upstream — git-копия официального репозитория в ветке `main`. В готовом EXE уже есть MinGit; при запуске исходников нужен системный Git.
- Для запуска батников и сетевых тестов — права администратора.
- Для Standard-тестов — системные `curl.exe` и `ping.exe`. В Windows 10/11 они обычно уже есть.

## Быстрый запуск

В PowerShell из папки проекта:

```powershell
py -3 -m venv .venv
& '.\.venv\Scripts\python.exe' -m pip install -r requirements.txt
git clone https://github.com/Flowseal/zapret-discord-youtube.git ..\zapret-discord-youtube
& '.\.venv\Scripts\python.exe' main.py --admin --repo '..\zapret-discord-youtube'
```

В готовом EXE достаточно нажать «Скачать zapret»; отдельная команда `git clone` не нужна.
Для последующих запусков из исходников можно использовать `Start.cmd`. Папка zapret и последняя выбранная конфигурация запоминаются.
При запуске без `--admin` права можно запросить кнопкой в окне.

## Результаты тестирования

HTTP/TLS-цель успешна, если `HTTP`, `TLS1.2` и `TLS1.3` имеют значение `OK`; её `Ping: Timeout` не отменяет успех.
`UNSUP`, `ERROR`, `SSL` и отсутствующие протоколы считаются ошибкой. Для ping-only цели нужен числовой ответ.

Средний ping считается по всем числовым ответам, включая цели с HTTP/TLS-ошибками; `Timeout` исключается.
Для `<1 ms` используется верхняя граница 1 мс. Количество целей берётся из отчёта, а не зафиксировано в коде.

Результат каждого завершённого батника записывается сразу. При незавершённом общем прогоне он помечается отдельно.
Во время общего прогона дата завершённых конфигураций остаётся видна. Отмена сохраняет полученные строки и не затирает прежний результат батником, который ещё не успел ничего проверить.
При отмене кнопкой возвращается ранее активная конфигурация; при закрытии окна она повторно не запускается.
Результаты изменённых файлов считаются устаревшими. Импорт не подтверждает дату исходного теста и соответствие текущей сборке.

Данные хранятся вне приложения:

```text
%LOCALAPPDATA%\ZapretClient\state.json         — результаты и выбор
%LOCALAPPDATA%\ZapretClient\state.backup.json  — предыдущая корректная копия
%LOCALAPPDATA%\ZapretClient\logs              — тесты и слепки ipset
%LOCALAPPDATA%\ZapretClient\git-logs          — вывод команд обновления
%LOCALAPPDATA%\ZapretClient\self-update       — сообщения о ходе замены EXE
```

## Обновления zapret

«Проверить обновления» получает актуальный commit `main` из официального `origin`, сохраняя рабочие файлы на месте.
При наличии изменений появляется «Обновить zapret». Применяется только проверенный commit через `git merge --ff-only`.

Обновление блокируется при работающем zapret, незавершённой операции Git или расходящейся истории.
Изменение только `lists/ipset-all.txt` допускается: клиент временно сохраняет его в Git stash, применяет fast-forward, восстанавливает точные исходные байты и убирает свой stash. Если upstream тоже обновил IPSet, пользовательский файл остаётся активным, о чём клиент сообщает в статусе.
Другие tracked/untracked-изменения блокируют обновление; файлы настроек, игнорируемые upstream через `.gitignore`, сохраняются. **Постоянный ZIP после обновления не создаётся.** Если обновление аварийно прервётся, временный stash внутри `.git` остаётся для восстановления IPSet.

Тесты выполняются собственным кодом клиента. Изменение `utils/test zapret.ps1` в upstream не останавливает диагностику и не помечает прежние результаты устаревшими.

## Обновление UI

Кнопка «Проверить версию UI» обращается к последнему релизу [Hezare0/Zapret-UI](https://github.com/Hezare0/Zapret-UI/releases). При наличии новой версии появляется «Обновить UI». Клиент скачивает автономный ZIP во временную папку, проверяет размер и SHA-256 из GitHub Release, извлекает EXE рядом с текущим, затем закрывается и запускает новую версию. После подтверждённого открытия нового окна прежний EXE отправляется в корзину. Если новый EXE не запускается, помощник возвращает прежний файл и записывает причину в `self-update`.

Для приватного репозитория нужен доступ через Git Credential Manager на этом компьютере; токен в настройках клиента и ZIP не хранится. При отсутствии доступа кнопка покажет ошибку. Установленный Python и системный Git для готового EXE не требуются. Автоматическая замена доступна только для `ZapretClient.exe`; при запуске из исходников GitHub Release можно проверить, а новый EXE нужно устанавливать вручную.

## Границы и совместимость

- Standard-тесты вызывают системные `curl.exe` и `ping.exe` из Python; upstream PowerShell не запускается. Цели читаются из `utils/targets.txt`; если файл пустой или отсутствует, используется встроенный набор из 17 целей.
- Внутри одной конфигурации HTTP/1.1, TLS 1.2, TLS 1.3 и ping запускаются параллельно, максимум 32 одновременные операции. Лимит можно задать переменной `ZAPRET_PROBE_PARALLEL` от 1 до 48. Конфигурации проверяются строго по очереди: сетевой фильтр `winws` общий для Windows.
- Семантика статусов curl сохранена: код выхода 0 означает `OK`, включая ответы HTTP 403/404; ошибки сертификата и DNS выделяются как `SSL`, неподдерживаемая TLS-версия — `UNSUP`. Каждый запрос ограничен 4 секундами, ping — 1 секундой ожидания ответа.
- При отмене клиент завершает только принадлежащие ему тестовые процессы и сохраняет уже завершённые конфигурации. Если сторонний `winws` запущен, прогон блокируется, чтобы не смешать результаты.
- Установка службы, настройки `service.bat` и DPI-тесты в текущую версию не входят.
- Клиент отслеживает принадлежащие ему процессы через Windows Job Object, включая дочерние процессы BAT `START`.
- Запуск батников меняет сетевую фильтрацию; upstream также может включать TCP timestamps. Глобальные настройки TCP клиент не восстанавливает.
- Фактическая доступность сайтов зависит от сети на момент проверки; после смены VPN или провайдера тест нужно повторить.

## Разработка и сборка EXE

```powershell
& '.\.venv\Scripts\python.exe' -m pip install -r requirements-dev.txt
& '.\.venv\Scripts\python.exe' -m pytest -q
& '.\Build.ps1' -OutputDirectory '.\dist'
```

Результат сборки — **`dist\ZapretClient.exe`**, один файл со всеми компонентами. При запуске внутренние компоненты автоматически распаковываются во временную папку.
Режим папки для разработки можно получить через `Build.ps1 -OneDirectory`; тогда необходимо переносить всю папку результата.
Существующий каталог результата не перезаписывается: для следующей сборки выбери другой `-OutputDirectory`.

Упаковщик запускается с изолированным `PATH`. Происхождение DLL проверяется; системная `icuuc.dll` в дистрибутив не включается.
Это предотвращает захват несовместимых библиотек из других установленных программ.
Официальный MinGit 2.55.0.5 скачивается отдельно при сборке, проверяется по закреплённому SHA-256 и упаковывается изолированно вместе со своими лицензиями.

Проверка именно упакованного приложения:

```powershell
.\dist\ZapretClient.exe --smoke-test .\checks\report.json --repo C:\zapret-discord-youtube
.\dist\ZapretClient.exe --smoke-cancel .\checks\cancel.json --repo C:\zapret-discord-youtube
```

Режим создаёт настоящее окно Qt, проверяет список, иконку, запуск Git и сохраняет JSON со снимком окна, затем выходит.
Батники и сетевые тесты он не запускает. Для проверки восстановления можно положить копию `state.json` в `checks\smoke-state`.
`--smoke-cancel` проверяет кнопку отмены и крестик на безопасном процессе PowerShell с ожиданием, без запуска zapret.

Основные модули: `gui.py` — интерфейс, `controller.py` — операции и контрольные сохранения, `updates.py` — Git-обновления,
`windows.py` — UAC/процессы, `results.py` — парсер, `storage.py` — постоянные данные, `diagnostics.py` — адаптер upstream.

Исходник иконки — `assets/zapret-client.svg`; перегенерация ICO: `python build_support/render_icon.py` в подготовленном окружении.
